# Dot Car Derby - Project Overview

## 🏁 Vision Statement
Transform the educational Dot AI simulation into an engaging, competitive, web-based racing game that teaches machine learning concepts through hands-on training and competitive gameplay.

## 🎯 Core Concept
Players train AI-driven "dot vehicles" to race on progressively complex tracks. Each player's dot has unique DNA (sensors, actions, learning capabilities) that can be customized and upgraded through performance and educational achievements. The game balances competition with education, making machine learning accessible and fun.

## 🎮 Key Features

### Player Progression System
- **Dot Driver Profile**: Player identity, skill level, stats, race history
- **Dot Vehicle Profile**: Performance characteristics, DNA configuration, upgrades
- **Skill-Based Advancement**: Progress through education completion and race performance
- **Upgrade Ecosystem**: Earn and unlock vehicle capabilities, sensors, training algorithms

### Training System
- **Client-Side Training**: Run ML training locally for performance and cost efficiency
- **Configurable DNA**: Define available sensors and actions
- **Restricted Customization**: Players configure within earned limits
- **Daily Epoch Limits**: Prevent grinding, encourage thoughtful training
- **Reward Engineering**: Players design reward functions within available parameters

### Racing System
- **Progressive Track Complexity**:
  - Level 1: Straight drag race (basic learning)
  - Level 2+: Curves, obstacles, multi-lap circuits
- **Performance Classes**: Race against similarly-equipped vehicles
- **Real-Time Competition**: Live races or time trials
- **Replay System**: Watch and learn from top performances

### Tournament System
- **Weekly Competitions**: Regular scheduled events
- **Ranking Tiers**: Based on track, vehicle class, skill level
- **Reward Points**: All participants earn progression currency
- **Podium Bonuses**: Top performers get premium upgrades
- **Fair Play**: Restricted environments prevent cheating

### Community Features
- **Knowledge Sharing**: Forums, strategy guides
- **Swap Meet Events**: Exchange training configs and techniques
- **Git Integration**: Share and fork training strategies
- **Educational Resources**: Tutorials, challenges, achievement badges

## 🎓 Educational Philosophy
1. **Problem-Solving First**: Focus on teaching computational thinking
2. **Approachable Language**: Use familiar metaphors and clear explanations
3. **Progressive Complexity**: Start simple, layer on advanced concepts
4. **Guided Discovery**: Help system teaches without hand-holding
5. **Community Learning**: Encourage collaboration and knowledge exchange

## 🏗️ Technical Pillars

### Web-Based Architecture
- **Cross-Platform**: Accessible via modern web browsers
- **Responsive Design**: Mobile and desktop support
- **Progressive Web App**: Offline training capability

### Security-First Design
- **No Custom Code Execution**: Sandboxed training environments
- **Tournament Validation**: Server-side race execution for competitions
- **SSO/OAuth Authentication**: Secure user access
- **Data Integrity**: Encrypted DNA storage, anti-cheat measures

### Performance Optimization
- **Client-Side ML**: Reduce server costs, improve responsiveness
- **WebGL Rendering**: Smooth race visualization
- **Efficient Data Sync**: Minimize bandwidth for DNA and race data
